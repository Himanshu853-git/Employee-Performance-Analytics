# Employee-Performance-Analytics

## About the Project

This project analyzes employee performance, engagement, and training data using SQL, Python, and Power BI.

The goal of the project is to understand employee trends, evaluate performance ratings, analyze engagement levels, and gain insights from training programs through data analysis and visualization.

## Tools Used

- MySQL
- SQL
- Python
- Pandas
- Seaborn
- Power BI
- GitHub

## Datasets

The project uses four HR datasets:

- Employee Data
- Employee Engagement Survey Data
- Training and Development Data
- Recruitment Data

## Project Steps

1. Imported and cleaned the data
2. Created SQL tables
3. Performed exploratory data analysis
4. Used joins and window functions for analysis
5. Created business-related SQL queries
6. Generated visualizations using Python
7. Built an interactive Power BI dashboard

## Power BI Dashboard

The dashboard includes:

- Executive Overview
- Employee Performance Analysis
- Employee Engagement Analysis
- Training Analytics

- Data Cleaning
